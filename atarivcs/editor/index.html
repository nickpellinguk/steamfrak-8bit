Keys

Clicking an existing object selects it, whatever the tool; the drawing tools only create on empty space. Arrow keys move the selection (3 px for ladders and items, a 4 px block for platforms, a row up or down). Shift + arrows resize it: a platform's rows (up/down) and width (left/right), a ladder's length. Delete removes it. Click the gutter to inspect a row.
